Safe Patch
----------
- Existing local Shopping List <-> Family Requests link preserved.
- Existing offline-first request/comment/update/delete synchronization preserved.
- Removed the shared FAMILY_SYNC_APP_KEY from the Android APK.
- Migrated Android family sync from legacy /v1 to authenticated /v2 endpoints.
- Each phone now receives its own high-entropy device token after register/join.

- Changing family code clears the old device token safely.
- First phone registers a new family code automatically.
- Second phone with the same code joins the existing family while pairing is open.
- Saving Family Settings on an already-linked phone reopens the pairing window for a new phone.
- All sync requests use HTTPS + Bearer device authorization.
- Backend PostgreSQL remains the shared persistent store.
- Legacy /v1 remains server-side only for migration/testing; Alpha83 no longer calls it.
